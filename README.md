# Калькулятор наценки (Tauri + React)

Небольшое десктопное приложение для macOS и Windows.

## Логика расчёта

1. Исходная сумма округляется **вверх** до шага из настроек (по умолчанию 100₽).
2. К округлённой сумме добавляется доставка согласно диапазону.
3. Наценка считается от суммы **уже с доставкой**:

```text
сумма с наценкой = (округлённая_сумма + доставка) × (1 + наценка_процент / 100)
```

4. Полученная сумма округляется **вверх** вторым, отдельным шагом (по умолчанию 100₽).

Пример: `1234₽` → округление `1300₽` → доставка `300₽` → база `1600₽` → наценка `35%` → `2160₽` → округление итога → `2200₽`.

Границы диапазонов **включаются**: сумма `400₽` попадает в `0–400`, а `401₽` — уже в `401–600`. Последний диапазон действует до бесконечности.

## Интерфейс

- Кнопка «Копировать» рядом с итогом кладёт цену в буфер обмена.
- Кнопка ☾/☀ в шапке переключает тёмную и светлую тему; выбор сохраняется, а при первом запуске учитывается системная настройка.
- Поле суммы принимает только цифры и одну запятую: минус, буквы и повторные разделители отбрасываются, отрицательная сумма не отображается.
- Строки «Округлённая сумма», «Доставка», «Сумма с доставкой» и «Наценка» по умолчанию скрыты. Их можно включить в скрытом редакторе формул (раздел «Показывать в главном окне»). Процент наценки при этом не показывается никогда — только сумма наценки.
- В редакторе диапазоны автоматически сортируются, отрицательные значения запрещены, а границы не могут пересекаться.

## Запуск

Нужны Node.js 20+, Rust и стандартные инструменты сборки (на mac — Xcode Command Line Tools).

```bash
npm install
npm run tauri:dev      # запуск в окне
npm run tauri:build    # сборка пакетов: .app/.dmg на mac, .msi/.nsis на Windows
```

Сборку пакетов удобно делать в GitHub Actions: `.github/workflows/build-installers.yml`. После пуша тега `v*` или запуска `workflow_dispatch` он собирает:

- Windows: один 32-битный установщик `.exe` (NSIS) и `.msi` — он работает и на 32-бит, и на 64-бит Windows (WOW64), поэтому заказчику не нужно выбирать разрядность;
- macOS universal (Intel + Apple Silicon): `Markup.Calculator_1.0.6_macos.dmg` и `Markup.Calculator_1.0.6_macos.app.zip` (внутри — universal-сборка).

Все файлы публикуются в один GitHub Release с прямой ссылкой без авторизации, если репозиторий публичный.

## Где хранятся формулы

Приложение ищет (или создаёт) файл `formulas.json`:

1. сначала **рядом с исполняемым файлом**;
2. если каталог только для чтения (например, установка в `Program Files` или подписанный `.app`) — в каталоге настроек ОС:
   - macOS: `~/Library/Application Support/com.runar.calculator/formulas.json`
   - Windows: `%APPDATA%\com.runar.calculator\formulas.json`

Актуальный путь виден в редакторе формул, там же есть кнопка «Показать в папке».

Формат файла — обычный JSON:

```json
{
  "version": 1,
  "passwordHash": "sha256:runar-calc-v1:...",
  "roundingStep": 100,
  "resultRoundingStep": 100,
  "delivery": [{ "id": "d1", "min": 0, "max": 500, "value": 100 }],
  "markup": [{ "id": "m1", "min": 0, "max": 400, "value": 80 }]
}
```

Пароль хранится как SHA-256 хеш, но при желании можно записать его открытым текстом — приложение поймёт и такой вариант.

## Скрытый редактор

- Горячая клавиша: **⌘ + Shift + F** на macOS / **Ctrl + Shift + F** на Windows. Других способов открыть редактор нет.

Начальный пароль: **Runar** (без кавычек).

В редакторе можно:

- менять два шага округления — исходной суммы и итога;
- менять пароль;
- включать/выключать строки детализации в главном окне (все выключены по умолчанию);
- добавлять и удалять диапазоны доставки и наценки;
- вручную нажать «Отсортировать», а при сохранении диапазоны всё равно автоматически сортируются, заполняются пропуски и убираются пересечения;
- последний диапазон всегда остаётся «до бесконечности».
